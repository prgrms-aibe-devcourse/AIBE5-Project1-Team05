Firebase Console에서 가져온 설정 정보를 아래에 입력하세요

📌 Step 1: Firebase Console 접속

1. Firebase Console에 접속하세요

2. 프로젝트 선택 → 프로젝트 설정(⚙️) → 일반 탭

3. "내 앱" 섹션에서 웹 앱의 Firebase SDK 구성을 확인하세요

⚠️ 이 페이지는 로컬에서만 사용되며, 입력한 정보는 외부로 전송되지 않습니다.
Firebase Console의 apiKey 값을 입력하세요
Firebase 프로젝트 ID를 입력하세요
Firebase Console의 appId 값을 입력하세요
Firebase Console의 messagingSenderId 값을 입력하세요
